# PNGTuber-Reactive

[![Download](https://shields.io)](https://github.com/ALEXI435/PNGTuber_Reactive/releases/latestt)

## About

PNGTube Ultimate is a program for creating virtual PNG avatars with the ability to change the displayed image based on **volume**, **pitch**, or a combination of both.

## Features

* 3 operating modes: **Volume**, **Pitch**, and **Volume + Pitch**
* Up to **10 state points** in each mode (excluding Idle)
* Customizable blinking for every state and Idle
* Select the audio device directly in the program
* Shaking
